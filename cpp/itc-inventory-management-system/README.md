# Inventory Management System

| **Course** | Introduction to Computing (ITC) |
| **Language** | C++ |
| **Type** | Console application |

A menu-based program that manages the product records of a shop. It stores the data in arrays and calculates the total value of every product automatically.

## Features
- Sort all records by Product ID or Total Value (ascending or descending)
- Add a new product record (Product ID must be unique)
- Delete a product record by Product ID
- Show products with quantity greater than or equal to X
- Show products with total value greater than or equal to Y
- Update the quantity or unit price of a product (total value is recalculated)
- Products are grouped in five categories: Electronics, Food, Clothing, Toys and Others

## How total value is calculated
- Total value = quantity x unit price
