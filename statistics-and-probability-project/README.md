# Statistics and Probability Project

| **Course** | Statistics and Probability |
| **Tools** | Microsoft Excel |
| **Type** | Data analysis project |

A semester project in which real-style data is collected in Microsoft Excel, visualized, and analyzed using descriptive statistics, the normal distribution, and hypothesis testing. Every calculation is done with Excel formulas and each result is interpreted in the writeup.

## Tasks
- **Task 1 - Data Collection and Histogram:** a dataset of lines of code written by a developer per day, an Excel histogram of the data, and interpretation of the distribution's shape, spread, and outliers
- **Task 2 - Descriptive Statistics:** mean, median, mode, and sample standard deviation computed with `AVERAGE`, `MEDIAN`, `MODE.SNGL`, and `STDEV.S` for the Unit_Cost, Unit_Price, and Profit columns, plus the coefficient of variation to compare their relative spread
- **Task 3 - Normal Distribution:** applying the properties of the normal distribution to compute probabilities and interpret results
- **Task 4 - Hypothesis Testing:** Z-test and t-test performed step by step, with the decision stated for each test

## Files
- `Statistics and probability project.docx`: the complete project writeup with Excel screenshots and interpretations
- `STATS PROJECT .xlsx`: the Excel workbook holding the datasets and all formulas
